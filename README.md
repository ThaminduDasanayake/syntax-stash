# Syntax Stash ⚡

> A curated reference manual and interactive workbench for modern web development.

**[syntax-stash.vercel.app](https://syntax-stash.vercel.app)** brings together client-side developer utilities, formatters, studios, and curated web resources wrapped in a modern neo-brutalist interface.

---

## ✨ Features

- **⚡ Client-Side Utilities**: In-browser tools for JSON, Regex, Diffing, Color palettes, Cron schedules, Hash generation, Mock data, Media conversion, and more.
- **📚 Curated Resources Vault**: Handpicked developer links spanning frameworks, animation engines, UI component libraries, AI tools, and typography foundries.
- **🔒 Privacy First**: All transformations, hashing, and parsing happen 100% locally in your browser.
- **🔎 Instant Search**: Fast fuzzy search and category filtering with URL-synced filters.
- **🎨 Neo-Brutalist Design**: Built with Tailwind CSS v4, custom theme tokens, and clean typography.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org) (App Router, React 19)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com) & [shadcn/ui](https://ui.shadcn.com)
- **Database & ORM**: [Neon Postgres](https://neon.tech) & [Drizzle ORM](https://orm.drizzle.team)
- **Auth**: [Better Auth](https://better-auth.com)
- **Icons**: [Phosphor Icons](https://phosphoricons.com)

## 🚀 Quick Start

### 1. Clone & Install

```bash
git clone https://github.com/ThaminduDasanayake/syntax-stash.git
cd syntax-stash
npm install
```

### 2. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build & Check

```bash
npm run build         # Build for production
npm run lint          # Run ESLint check
npm run format:check  # Check code formatting
```
